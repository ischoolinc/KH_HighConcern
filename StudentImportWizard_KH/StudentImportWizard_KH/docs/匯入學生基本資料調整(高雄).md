# 匯入學生基本資料 — 家長欄位別名調整紀錄（高雄版）

## 問題描述

匯出學生基本資料後，Excel 欄位標題已改為 `家長1`／`家長2` 用語，但匯入規格（`JH_S_BulkDescription`）與內部 XML 產生邏輯仍使用 `父親`／`母親` 欄位定義。

若不做別名轉換，Excel 的 `家長1`／`家長2` 欄位會被視為不支援欄位，無法選取與匯入。

## 目標

在**不修改** `JH_S_BulkDescription`、不改變父親／母親 XML 結構的前提下，讓 Excel 可使用 `家長1`／`家長2` 標題，內部仍對應既有 `父親`／`母親` 欄位定義。高雄版特有邏輯（局端傳送、國籍驗證、新增模式勾選行為等）維持不變。

## 修改檔案

| 檔案 | 說明 |

| `StudentImportWizard.cs` | 欄位選擇 ListView 顯示別名；識別欄／驗證欄下拉選單 UI 別名；內部比對仍使用父親／母親名稱 |

- 資料庫欄位名稱、服務請求元素名稱
- 其他非家長相關匯入邏輯

## 修改的類別與方法

### `JHSchool.dll`（相依組件更新）

#### `SheetColumn`

- `SourceName`：保留 Excel 原始標題（用於 UI 顯示）
- `Name`：內部匯入欄位名稱（用於 BulkDescription、驗證、產生 XML）
- `DisplayText`：回傳 `SourceName`
- `SetInternalName(string)`：寫入正規化後的內部名稱並更新群組資訊

#### `SheetReader`

- `NormalizeParentImportFieldName(string)`：集中別名轉換
- `NormalizeParentImportFieldNames()`：重建以內部名稱為 key 的欄位集合
- `GetValue(string)`：以內部名稱（如 `父親國籍`）查詢，仍從原始 Excel 欄位位置讀值

#### `WizardContext`

- `RefreshImportSource()`：於 `BindSheet` 後立即呼叫 `NormalizeParentImportFieldNames()`

### `StudentImportWizard.cs`（高雄版）

#### `GetParentAliasDisplayText(string)`

將 `BulkColumn.DisplayText` 轉為下拉選單顯示用語：

```text
父親* → 家長1*
母親* → 家長2*
```

#### `GetImportDisplayName(SheetColumn)`

匯入欄位 ListView 顯示名稱，優先使用 Excel 原始標題（含家長1／家長2 別名）。

#### `BulkColumnOption`（private class）

包裝 `BulkColumn` 與 UI 別名文字，供 `cboIdField`／`cboValidateField` 使用。

#### `ImportItem`（private class）

- 新增 `InternalGroupName`／`InternalFieldName`
- 建構子改為 `(displayName, internalGroupName)`，分離 UI 顯示與內部比對

#### `wpCollectKeyInfo_AfterPageDisplayed()`

- 識別欄／驗證欄下拉選單改加入 `BulkColumnOption`
- 空驗證選項以 `BulkColumnOption` 包裝

#### `wpCollectKeyInfo_NextButtonClick()`

- 由 `BulkColumnOption.Column.DisplayText` 寫入 `Context.IdentifyField`／`Context.ShiftCheckField`
- 選取空驗證選項時明確設為 `string.Empty`

#### `DisplayColumns()`／`GroupSheetColumn()`

- 顯示名稱使用 `GetImportDisplayName()`
- `AcceptColumns`、識別欄／驗證欄比對使用 `InternalFieldName`／`InternalGroupName`
- 保留高雄版新增模式預設不勾選、姓名必勾等既有行為

## 別名轉換實作位置

```text
RefreshImportSource()
  → SheetReader.BindSheet()
  → SheetReader.NormalizeParentImportFieldNames()
  → AcceptColumns 交集比對
  → 驗證 / GenerateInsertRequest / GenerateUpdateRequest
```

`StudentImportWizard` 會在選檔、驗證前、正式匯入前多次呼叫 `RefreshImportSource()`，別名轉換每次都會重新套用。

## 原始 Excel 標題如何保留

- `SheetColumn.SourceName` / `DisplayText` = Excel 原始標題（如 `家長1姓名`）
- 讀取儲存格以 `AbsoluteIndex` 為準，不依賴標題字串定位實體欄位
- `SheetReader.GetValue("父親國籍")` 可正確讀取 Excel 欄位 `家長1國籍` 的資料

## 內部欄位名稱如何使用

- `SheetColumn.Name` = 正規化後內部名稱（如 `父親姓名`）
- `Context.SelectedFields`、`Context.ValidateColumns`、`Context.IdentifyField`、`Context.ShiftCheckField` 均使用內部名稱
- `ValidateNationColumn()` 仍以 `父親國籍`／`母親國籍` 為 key，無需修改

## 限制與注意事項

1. 同一份 Excel **不可同時**出現會正規化成相同內部名稱的欄位（例如同時有 `家長1姓名` 與 `父親姓名`），否則會觸發「重覆的欄位名稱」錯誤。
2. 複合欄位實際 Excel 標題格式為 `家長1:學歷`（與匯出端一致）；`家長1其它資訊:學歷` 格式亦可處理。
3. `Library/JHSchool.dll` 必須為含別名正規化支援的版本，否則僅更新 `StudentImportWizard.cs` 無法完成 Excel 欄位比對。
4. 未修改 XML 資源；內部處理仍使用父親／母親欄位名稱。
